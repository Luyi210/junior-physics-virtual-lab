# 光学证据舱：POE 论文研究版

这是从 V2 中独立出来的初中光学研究型产品。它不会修改原学生端，而是直接复用 `@physics-lab/physics` 的物理模型和 `@physics-lab/harness` 的概念图、证据量规与分层提示。

## 当前研究任务

1. 光的反射定律：测量基准、三组角度对照与漫反射迁移。
2. 凸透镜成像：物距、像距、光屏对焦与相机迁移。
3. 三棱镜色散：白光/单色光、棱镜姿态、光屏距离与色带落点。
4. 人眼视力矫正：焦点诊断、镜片对照与远视迁移。

每个任务统一采用：预测（Predict）→观察（Observe）→重新判断（Reconsider）→解释（Explain）→迁移（Transfer）。其中“重新判断”属于POE解释阶段的前置环节，用来保存预测与观察之间的认知冲突证据。

第二轮循证改造进一步加入：

- 预测理由与1—5级初始信心度；
- 观察后的符合/冲突/不确定标记；
- 修正答案、修正理由和观察后信心度；
- 逐任务“学习主张—可观察证据—任务”地图；
- 不同实验的关键对照门槛，而不是简单记录次数；
- 未经提示的初始预测与独立迁移评价。

## 沉浸交互工作台

- 反射实验可直接拖动光源，角度、光路和数字量角器同步变化；
- 凸透镜光具座支持拖动蜡烛与光屏，并用动态清晰度仪表反馈离焦程度；
- 色散实验可拖动棱镜旋转把手与光屏，支持白光、RGB 合光和单色光三种光源；
- 视力矫正加入近视/远视双病例，可将凹、凸透镜拖入试戴槽完成处方验证；
- 每个实验提供情境预设、实时仪器 HUD、实验挑战、证据胶片与沉浸全屏；
- 光光新增装置扫描状态与“下一步、检查证据、组织解释”快捷交互。
- 首次进入每个实验的观察阶段会出现光光教学弹窗；
- 教学过程分为“认识装置—亲手操作—记录对照—归纳证据”四步，并会高亮当前操作区域；
- 关闭后可随时通过观察页上方的“光光教学”按钮重新打开。

## 光光研究功能

- 根据当前 POE 阶段提供不同反馈；
- 读取最近一组装置记录；
- 标记预测选项对应的典型误概念；
- 调用共享概念图中的三级提示阶梯；
- 拒绝直接代答，要求学生回到实验条件与证据；
- 记录提示调用次数，用于匿名学习分析。
- 预测阶段关闭内容提示，避免污染初始观念；
- 提示层级随装置证据逐步开放，迁移阶段再次关闭。

## 数据与隐私

- 默认只使用匿名研究编号；
- 会话保存在浏览器 `localStorage`；
- 支持导出 JSON 完整记录与 CSV 指标表；
- 正式研究前应完成知情说明、教师内容审查和数据管理方案；
- 当前评分属于透明的形成性量规，不应直接解释为标准化能力测量。

论文来源与每项产品改动的对应关系见 [docs/LITERATURE_BASIS.md](docs/LITERATURE_BASIS.md)。

## 启动

在 V2 根目录运行：

```bash
npm run dev:optics
```

默认地址：`http://127.0.0.1:5175`

构建研究版：

```bash
npm run build:optics
```
