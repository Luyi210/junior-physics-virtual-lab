# 格物实验室用户使用指南

更新：2026-11-23。适用于当前初高中合版公开演示。网页版入口：<https://luyi210.github.io/junior-physics-virtual-lab/#/guide>。网页右上角可打印或保存为 PDF。

## 1. 第一次打开

1. 打开[平台首页](https://luyi210.github.io/junior-physics-virtual-lab/)。
2. 选择“初中探索”“高中实验室”或“教师端”。公开演示可直接作为访客体验。
3. 先阅读页内弹出的引导，再选一个实验。实验时建议先预测、只改变一个主要条件、比较现象、保存证据。

首页和高中实验室顶部均有“使用指南”入口。首次引导关闭后，仍可从页面的“平台向导”等按钮重新打开对应引导。

## 2. 初中学生

入口：[初中探索](https://luyi210.github.io/junior-physics-virtual-lab/#/student)。

1. 在学生页选择光、声、力、电、热或密度领域，也可以从生活问题寻找实验。领域没有必做顺序。
2. 进入实验后拖动装置、调参数或操作开关，观察图像、读数与现象的变化。
3. 打开光光，询问下一步、变量控制或观察解释。光光的实验定位和参数写入只覆盖已支持的实验。
4. 在[实验记录本](https://luyi210.github.io/junior-physics-virtual-lab/#/student/notebook)保存自己写下的操作、观察和新问题；需要迁移时使用“导出可迁移学习轨迹”。

自由探索记录保存在当前浏览器，不会自动进入学校账号。真实班级任务必须连接独立教学后台并登录学生账号。

## 3. 高中学生

入口：[高中实验室](https://luyi210.github.io/junior-physics-virtual-lab/#/high-school)。

1. 从实验目录选择实验，先看实验目标与模型适用条件。
2. 改变一个变量，观察二维装置、可用的三维视图、图像与读数。动态实验可用播放、暂停、慢放和适用的时间轴反复观察；观察速度不会改变物理计算时间。
3. 保存当前读数，比较不同条件。需要留存副本时，在实验页导出 CSV。
4. 打开力力，询问变量控制、当前卡点、记录复盘或误差分析。将助手的建议与实际读数及教材核对。

高中访客、演示和账号档案按身份在**当前浏览器**中分开保存；高中账号档案目前不会自动同步到学校后台。更换设备、浏览器或清除站点数据前，请先导出需要保留的读数。

### 题目可视化

[题目可视化](https://luyi210.github.io/junior-physics-virtual-lab/#/high-school/problems)可粘贴题干。当前只有**抛体运动**和**弹簧静态平衡**两类符合格式、带必要数值与单位的题目能生成可计算场景。缺少条件或属于其他题型时，页面会提示补充或更换题目；不能将任意题目自动生成仿真。

## 4. 光光和力力

- **光光**在初中实验页提供分步提示、实验定位、观察表述核对等功能。
- **力力**在高中专区提供当前实验状态、变量与方法速查、记录复盘和误差分析等功能。
- “输题找实验”只覆盖已接入的实验与题型。情境同桌使用预设教学观点；草图白板供自己画图，助手不会识别具体线条。
- 网络或 AI 服务不可用时，部分回答会退回本地规则。助手可能出错，重要结论要用实验数据与教材核实。

## 5. 教师端

入口：[教师端](https://luyi210.github.io/junior-physics-virtual-lab/#/teacher)。公开网页可体验本地演示工作区。教师可浏览教学总览、备课与课堂页面。

真实学校使用时，需要独立部署教学后台，教师使用有效账号登录，之后才能管理学生与班级、创建课例、发布任务，并查看已同步的课堂证据与报告。演示数据不能视为真实学生提交或学校学情记录。

## 6. 手机使用

手机浏览器打开同一网站即可进入实验。高中实验在手机上优先显示可操作的二维装置；支持的设备可切换三维。二维画面可缩小、放大或重置，缩放只改变观看大小，不改变物理参数和读数。表格可横向滑动。建议使用较新浏览器，保留站点数据空间；无痕模式不适合长期保存本机记录。

## 7. 常见问题

**为什么换一台手机看不到以前的记录？** 公开演示的自由探索与高中读数主要保存在生成记录的浏览器里。真实班级任务必须连接后台并确认同步成功。

**三维打不开怎么办？** 切换二维装置继续。二维视图仍可使用相同实验参数、物理计算与读数。

**题目没有生成场景怎么办？** 检查是否属于当前支持的两类题、是否包含必要数值与单位；也可直接在实验目录找相关实验。

**保存失败怎么办？** 保留当前页面，先复制重要文字或导出页面提供的 CSV／学习轨迹，再重试。导出前不要清除浏览器站点数据。
