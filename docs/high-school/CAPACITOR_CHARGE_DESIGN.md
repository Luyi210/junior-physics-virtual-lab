# 电容器充放电实验设计

第二十二阶段，2026-11-11。入口为 `/high-school/experiments/capacitor-charge`；课程依据、开源取舍与教材核验范围见[研究依据](CAPACITOR_CHARGE_RESEARCH.md)，实际检查结果见[验收记录](ACCEPTANCE_STAGE_22.md)。

## 学习与操作

用中位断开的转换开关选择接电源、经电阻放电或断路。公共端经 R 与电流表连接 P 极板；N 极板接负端，电压表并联两板。放电闭环绕过电源，开路时不流过电阻；两板之间没有导电连线或穿越介质的电荷动画。二维接点、原生按钮与三维接点提交同一个模式意图，三维拖动不当作点击。

固定正方向为常规电流流入 P 极板。电压为 V(P)−V(N)，Q 是 P 板电荷，N 板为 −Q，整个电容器净电荷为零。仪表显示有符号电流，放电箭头反向。场景不重新计算电学公式，只消费纯模型的 SI 数值；局部读数可换算为 mA、μC、mJ。

参数 R 使用 1—10 kΩ，C 使用 100—1000 μF，E 使用 1—12 V；默认 10 kΩ、470 μF、6 V，τ=4.7 s。每轮固定参数、从零电压开始，观察窗为20RC。改参数、重新计时或从终点再次播放都建立新轮次，已有档案保留。开关切换延续当前 U/Q/储能；暂停仅停止仿真时钟。观察窗结束不会把电压强制写成 E 或0。

## 分段模型与记录

`packages/contracts` 定义 `CapacitorHistory`：`kind:'capacitor-rc-v1'`、安全字符串 `runId`、`initialVoltage:0` 和完整 `segments:[{startTimeSeconds,mode}]`。首段从0开始、后段时刻严格递增且模式发生变化，最多32段。重复模式不增加段；同一仿真时刻的零时长切换由切换函数规范化。达到上限拒绝继续添加，不截断前序过程。

`packages/physics/src/highSchool/capacitor.ts` 按完整历史连续重放，每段 U₀ 继承前段终点。客户端不能另传段初电压或派生值来替代历史。动态实验的第4个模拟参数必须提供历史；其他实验不能带入此历史。每段使用解析指数方程，能量分别核算电源累计功、电容储能和电阻耗散。曲线仅绘制本轮已经发生的过程，每次切换同时保留电流左右极限，不预画未来模式。

正常档案、失败补写与待恢复副本均保留完整历史及原始参数；读取不会将缺历史的数据当作零初值充电。CSV含原始历史JSON，记录表和恢复面板可查看各段。复制到课堂报告仍由学生明确选择与预览，保留原保存读数和历史；元数据可由历史重算，但不以当前模型覆盖旧读数。原始档案仍是本机保存，课堂得到的是可编辑文字副本。

## 分析与力力

仅按同参数、同轮次、同一段的完整历史前缀分组。横轴为段内时间，纵轴由保存电压计算 `ln(|U−U∞|/1 V)`，接电源时 U∞=E，放电时 U∞=0；至少3个不同横坐标才拟合。截距不强制为零，负斜率才可估计 τ。开路、零电压差及不可取对数的读数不能生成时间常量结论。对数图是模型关系检查，不是独立实物测量。

力力接收当前历史及最近最多30条各自独立的保存历史，服务端严格校验后重算 U/I/能量，丢弃客户端的派生答案。当前模式、段号和完整过程进入经过校验的模型参考；它不按记录数量判断学习完成。请求体上限为128KiB，语义上仍限定每轮32段、最近30条，满足边界也不静默裁剪。

## 代码边界与未实现项

物理重放与分组在 `packages/physics`；共享历史类型在 `packages/contracts`；力力校验在 `packages/harness`，网络调用与权限在 `apps/api`。工作台持有当前历史，`components/Capacitor*` 与 `capacitorGeometry.ts` 只处理装置显示及交互；`experiments/capacitorEvidence.ts` 负责档案校验与课堂文字来源。

未模拟漏电、击穿、电表负载、寄生参数、改变 C 时的外界机械功或双电容电荷分享；未加入独立手动电表或 I—t 面积工具。没有复制 PhET/CircuitJS 的代码或素材，也没有新增运行时第三方依赖。真实浏览器、低性能GPU、触屏、教师审阅、2025课标全文与学校实际用书仍待核验。
