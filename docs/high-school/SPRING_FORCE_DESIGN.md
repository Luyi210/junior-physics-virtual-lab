# 弹簧伸长与弹力：第十三阶段设计

日期：2026-11-11。实验ID为`spring-force`，独立高中目录的第7项开放实验，其余17项保持规划状态。此文记录设计和证据边界，不代替阶段运行验收。

## 课程定位

沿用[课程对应表](./CURRICULUM_MAP.md)已有的2020修订版学生实验关联，以及人教版必修第一册第三章弹力的定位。未重复请求失败的2025课标正文或教材下载，未增加未经核实的页码。本页探究目标为：在**模型给定的线性范围**中建立力与伸长量的关系，用保存数据的图像斜率估计劲度系数。教材实体实验的读尺、装配和真实弹性限度探究不能由本页替代。

## 静态模型与量的定义

| 量 | 本轮取值/定义 |
| --- | --- |
| 劲度系数k | 10～50 N/m；同一组拟合保持不变 |
| 原长L₀ | 0.10～0.30 m；无载荷时的弹簧长度 |
| 悬挂总质量m | 输入0～250 g，**含托盘**，计算前除以1000换为kg；0表示总载荷为零 |
| 重力加速度g | 固定9.8 m/s² |
| 弹力大小F、伸长量x、总长L | 静态平衡时`F=mg=kx`，`x=L−L₀`；F与重力大小相等、方向相反，合力为零 |
| 线性范围 | 预设`0≤x≤0.25m`。本页最大组合`m=0.25kg, k=10N/m`给出`F=2.45N, x=0.245m`，仍在预设范围内 |

弹簧质量忽略；改变载荷后直接计算新的平衡状态，没有振动、阻尼等待时间、塑性形变或滞回。上限0.25m是教学模型约定，不是由材料试验估出的真实弹性限度。改变k或L₀应作为另一组条件；不能把不同弹簧的点混拟合为同一条F—x关系。

## 操作与证据

1. 固定k和L₀，查看无载荷时的原长参考位置。原长、总长、伸长量在2D和3D中按同一模型长度换算，挂件高度不计入弹簧长度。
2. 分次增加悬挂总质量，每次保留总质量、原长、总长、伸长量和弹力大小及单位；至少使用三个不同伸长量，零载荷点可作参考。
3. 再逐次卸载，比较相同载荷、相同k和L₀下的记录。本理想模型应返回相同长度，不能据此证明真实弹簧没有滞回或能量损耗。
4. 用保存记录构建F—x图像、估计斜率k；说明图像的横轴是**伸长量而非总长**，力的单位是N而非g。只保存相同载荷的重复点不构成足够的拟合跨度。

所有自动读数来自模型，不是学生独立手动读尺或实体器材数据。用这些数据估k是在检验已选模型内部关系，拟合吻合不能证明真实材料在任意载荷下线性，也不能把模型生成数据说成带有真实测量误差。记录与图像应保留当时条件，恢复默认不更改旧记录。
