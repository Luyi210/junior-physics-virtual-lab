## 模型与参数

| 参数 | 范围与单位 | 默认值 |
| --- | --- | --- |
| `force1N`、`force2N` | 0～5 N | 3 N、4 N |
| `angle1Degrees`、`angle2Degrees` | −180°～180°，从+x轴逆时针计 | 0°、90° |
| `trialForceN` | 0～10 N | 5 N |
| `trialAngleDegrees` | −180°～180° | 0° |

两个力的共同作用点固定，参数变化直接更新静态状态，时刻为0，无需播放。按分量计算：

`Rₓ=F₁cosα+F₂cosβ`，`Rᵧ=F₁sinα+F₂sinβ`，`R=√(Rₓ²+Rᵧ²)`。

学生试配力独立保存为参数，不自动被模型合力替换；残差向量为`F试−R`，残差大小为其模。默认试配力是沿+x轴的5 N，而默认合力是分量(3,4) N；大小相等仍不能代替方向比较。合力为零时没有方向；任一分力为零时两力夹角没有定义。界面和力力必须使用方向/夹角有效标记，不把占位角度当作可观察方向。

等效力与合力同向，平衡力与合力反向。残差0.05 N只是教学对照阈值，既非仪器精度，也非学习完成判据。图上的长度表示N，不是绳长或物体位移；2D/3D应读取同一模型分量和统一比例，平行四边形辅助线只用于矢量构图，不表示额外外力。

## 操作与分析约定

1. 先给定两力，预测合力方向；独立拖动试配力端点或用数值控件设置大小和方向。系统可以显示模型对照，但不自动填入试配答案。
2. 对照分量与同一比例的矢量图，保存完整参数、独立试配选择、模型读数和单位。试配是虚拟选择，不是独立手动测力计记录；自动模型量与该选择的来源要分别说明。
3. 固定两个非零力的大小，例如3 N和4 N；固定第一力方向0°，改变第二力方向60°、90°、120°。每次保存后得到至少3个不同夹角余弦。也可整体旋转装置，但整体旋转或只改试配力不会增加新的夹角横坐标。
4. 分析横轴`cosθ`、纵轴`R²`，其中θ为0°～180°的两力夹角。不同方向角不一定意味着不同`cosθ`，例如相对第一力的+60°与−60°具有相同余弦。

关系为`R²=F₁²+F₂²+2F₁F₂cosθ`。保留自由截距，斜率对照`2F₁F₂`，截距对照`F₁²+F₂²`；默认两力分别对应24 N²和25 N²。此处`R²`表示合力大小平方，不能与拟合优度的统计决定系数混用。

工作台分析应使用记录中保存的量；力力只接收最近最多30条保存条件，重新计算这些条件对应的模型量并注明来源，不信任外部提供的拟合结果。不同两力大小分组；零分力不做夹角关系拟合。试配力不作为这一模型关系的拟合输入，因此完美拟合不证明学生试配正确，更不证明真实测量准确。
