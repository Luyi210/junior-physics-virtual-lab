# 高中实验室：产品与界面设计

## 目标与入口

面向高中学生的自由探究与教师演示，沿人教版必修、选择性必修六册组织。初中继续用原有 `/student` 与 `/student/explore/*`；高中使用 `/high-school` 和 `/high-school/experiments/:experimentId`。高中目前开放目录内24项实验。第二十四阶段补入其余14项的专属二维/三维装置、模型、读数、数据分析与力力指引；开放代表可交互模型已接入，不等同于真实设备或教材逐项审定。详见[本轮验收记录](EXPANSION_ACCEPTANCE.md)。

自由探究读数暂存浏览器，可导出 CSV。第十四阶段建立的课堂链路现已覆盖24项开放实验，接入班级任务和既有四段课堂报告：教师选课发布，学生从任务进入、明确选择本机读数生成文字副本，保存到账号后由任课教师查看。仪器原始档案没有自动云同步。第十九阶段已接入针对报告版本的教师文字反馈；评分仍未实现。

新本机档案使用 v3 命名空间，按后台地址、学校、角色、账号及实验分开保存；访客和演示档案独立，访客数据仍由同一浏览器的使用者共用。两个入口同时留有登录状态且没有明确选择时，先选择档案归属。过期账号保留原档案，只读与导出可用，重新登录后恢复保存。

每条记录独立保存，多标签追加不会整表覆盖；清空切换存储代次，其他页面不会恢复旧快照。失败写入保留在原归属的页面会话缓存，切换后返回仍可导出。旧 v1/v2 数据原位保留，仅在“升级前的公共本机档案”中显式查看和导出，不自动归入某个账号、不发送给力力。这里的账号分区是本机数据组织，不是加密存储或学校后台权限控制；只有学生明确加入课堂报告的文字走后台保存流程。

自动与手动记录的异常区提供独立“重试本机保存”，无需新增读数，达到120条新增上限后仍可补写原编号。重试检查当前身份与存储清空代次，失败时保留CSV救援入口；120条不是跨标签的原子容量锁，不截断已经保存的记录。恢复默认条件同时重建数字编辑器，清除无效草稿；普通改参和重新计时不会重建所有编辑器。双缝探针位置不作为条纹变化条件，移动探针保留A/B/N与同次观察去重，实际波长、缝距和屏距变化才要求重新读尺。详见[第十一阶段记录](ACCEPTANCE_STAGE_11.md)。

新增时若不能读取当前档案状态，读数进入独立“待恢复”区，不自动合并，也不参与拟合或力力上下文。学生可以查看原条件和手动原始读数、单独导出CSV，再确认保存到当前档案。确认绑定目标与整批内容；发生变化必须重新核对，部分失败保留未确认副本。手动异常条目禁止整批恢复并提供完整原始JSON备份；不以理论值修正原始读数。恢复保留原编号，不因120条上限截断。副本首先存在于页面会话内存，关闭或刷新前应导出。localStorage没有跨标签原子事务保障，详见[第十二阶段记录](ACCEPTANCE_STAGE_12.md)。

网页沿用 HashRouter，本机直接地址使用 `http://127.0.0.1:5174/#/high-school`；文中不带 `#` 的路径为应用内部路由。

## 班级任务与课堂报告

教师备课目录按初中、高中区分，班级可选择高一至高三。新高中课例提供与现有控件对应的问题、控变量、证据和反思提示；切换模板会同步这些字段，不改写已保存课例。共享课堂注册表同时供前端跳转和后台创建校验使用，筹备实验不允许布置为可操作任务。

高中工作台只读取地址中明确成对给出的任务/会话，不继承其他页面残留的“当前任务”。先核对学生、学校、实验、任务与会话，再显示课堂提示和报告链接；任务关闭后的课例说明可能不可读，但已核对归属的历史报告仍可进入。自由探究没有课堂链接，也不会自动上传读数。

课堂报告中的读数选择器默认不勾选。学生逐条选择自动模型采样或手动虚拟仪器读数、查看完整文字，再确认加入“测量数据与观察”。同一实验历史自由探究读数可能也在列表中，因此保留原编号、创建时间、仿真时刻、全部参数与单位；手动记录另保留原始读数、计数、分辨率、假设和提示。预览不会裁剪为力力使用的最近30/10条。追加保留原文，超过12000字符时明确拒绝、不截断。

确认动作重新核对后台会话、报告版本、当前身份、原正文及所选内容。身份变化、已完成、版本冲突或本机档案异常会阻止追加；待恢复副本、无法校验手动记录和旧公共档案不参与。加入的是可编辑文字副本，保存状态由既有报告页面显示，不能称为系统认证的原始附件、老师已批阅或已完成提交。报告仍可为空；“完成实验”表示会话结束并只读，不是评分或审核。

完整范围、测试与剩余边界见[第十四阶段验收](ACCEPTANCE_STAGE_14.md)。

课堂文字报告与高中仪器原始档案分别确定归属。报告始终使用学生登录通道，按后台、学校、学生和会话保存本机副本，不随教师/游客仪器档案选择器切换。到期后只读；重新登录使旧页面回调失效，同时保留原账号草稿。旧报告和其他页面、损坏副本提供显式查看与JSON备份，不能自动认领旧后台数据。完成实验前同步本页并检查其他页草稿，存在其他页草稿时说明完成后的限制并要求再次选择。详情见[第十五阶段验收](../ACCEPTANCE_STAGE_15.md)。

## 视觉与操作

高中采用米白纸张、深墨绿仪器、铜橙强调色，保留中文阅读层次。首页强调课程和问题，工作台强调装置、参数、图像与证据；不展示虚假的学生人数、学习评价或完成率。

工作台主要区域依次为：

1. 教材定位与探究目标。
2. 3D 装置和可切换的 2D 示意；旋转缩放视角不改变物理状态。
3. 时间控制与实时模型读数；静态弹簧、电学和干涉不伪造运动时间。
4. 带单位、范围和精确数值输入的参数。改变参数重新计时，保留旧记录的参数快照。
5. 模型曲线、关系式与适用条件。
6. 实验采样表、当时条件和 CSV 导出。
7. 记录分析：选择物理关系和同条件组，查看图点、来源、拟合与不足原因。
8. 力力提供随实验变化的提示，学生保留实验操作与结论的决定权。

单摆和双缝还提供独立的手动虚拟仪器区：学生起止计时或定位屏幕条纹，自行输入完整周期数/间隔数，再保存原始读数与推算值。手动档案与自动模型采样分开存储和导出。力力在学生提问时接收最近最多10条手动读数，独立校验与解释；自动采样仍使用自己的分组拟合路径。详见 [第三阶段说明](ACCEPTANCE_STAGE_3.md) 与 [第五阶段说明](ACCEPTANCE_STAGE_5.md)。

3D 仪器以清晰表达结构和空间关系为目标，并注明示意缩放；不得用与模型矛盾的绳长、错误的电表接法或随意改变的比例制造“真实感”。不支持 WebGL 的设备仍能使用参数、图像、采样和二维装置。动画使用固定时间步，页面隐藏时暂停。

双缝二维光屏使用完整1601个模型光强点生成渐变，光屏和观察点标记共用 −20～20 mm 的坐标映射，不因显示抽样丢失窄条纹。匀变速三维中的“+x 正方向”由世界坐标中的空间箭头表示，不随相机翻转成另一物理方向，也不代表物体始终沿正向运动。这些修正已完成源码、SSR和几何验证，真实浏览器显示仍待验收。

弹簧实验提供逐级加载与卸载：总质量含托盘，0 g表示没有悬挂物；改变载荷后直接显示静态平衡，不演示振荡。二维、三维的标尺比例固定，原长、总长和伸长标记共用长度映射。先记录无载荷原长，再记录至少三种载荷，调整不会自动保存。详见[弹簧设计](SPRING_FORCE_DESIGN.md)与[第十三阶段验收](ACCEPTANCE_STAGE_13.md)。

共点力实验以静态矢量板比较两个力与学生独立试配的等效力。二维支持端点拖动、键盘和数值输入，三维可观察共点和平行四边形；预设不会填写试配答案或自动记录。零合力没有方向，零分力不作夹角图线。0.05 N只是教学对照阈值；没有测力计校准、橡皮条形变或独立实测。详见[共点力设计](FORCE_COMPOSITION_DESIGN.md)与[第十六阶段验收](ACCEPTANCE_STAGE_16.md)。

## 从记录到关系分析

同一实验允许选择多种关系，先确定横纵轴和固定条件，再选择对应记录组。纯物理包负责分组、派生量与拟合；页面只显示结果、记录来源和适用条件。没有足够不同取值、控制条件不一致、读数缺失或数值退化时，显示明确原因，不补造历史数据。

| 实验 | 记录分析方式 | 操作要求 |
| --- | --- | --- |
| 匀变速 | 默认以相邻位置差/时长求区间平均速度，对时间中点拟合；保留模型瞬时速度–时间关系 | 固定全部参数，至少4个不同时刻形成3个区间；重复时刻先平均位置，各区间可以不等长 |
| 共点力合成 | 保存合力的R²–cosθ带截距拟合 | 固定两个非零分力大小，至少3种不同cosθ；斜率2F₁F₂、截距F₁²+F₂²。试配力不参与此关系，拟合不评价试配是否完成 |
| 弹簧伸长与弹力 | 保存的F–x作带截距拟合，斜率估k | 固定劲度系数和原长，至少三种不同伸长量；x=L−L₀，不能用总长代替；质量以g输入，力以N记录 |
| 牛顿第二定律 | a–F合与a–1/M总分别检验力与质量的影响 | 前者固定总质量并转移小车/挂码质量；后者固定挂码、阻力与行程，只改变小车质量；两者均只分析能够启动的情况 |
| 平抛与斜抛 | x–t、vᵧ–t与(h₀−y)–t² | 最后一项仅用于竖直初速度为零；斜抛标为不适用，原有分运动关系仍可选择 |
| 单摆 | 小角条件下T²–L | 固定摆角和质量；大于10°不反推g，数值周期不冒充独立秒表读数 |
| 电动势与内阻 | 固定E/r的U–I | 改变负载；I>0且r>0时U<E，理想零内阻时U=E |
| 双缝 | 近轴间距–屏距的模型一致性检查 | 固定其余条件；间距来自模型公式，不能冒充手动选点测量 |

位置区间点有独立来源标记，保留两端所有原记录编号、起止时刻与位置。详情表提供Δx、Δt、中点和速度，显示编号排序不改变区间方向。只有匀变速模型的区间平均速度等于中点瞬时速度；相邻区间共享端点，不能当作独立的实体测量。统计继续按不同横坐标的均值点等权拟合，残差不代表原位置读数的离散程度。手动虚拟读数仍单独保存，不混入这些自动模型采样关系。

阶段10已通过完整本地自动检查及隔离服务HTTP联调，实现与证据见 [第十阶段验收记录](ACCEPTANCE_STAGE_10.md)。真实浏览器操作和视觉验收仍未完成。

## 力力

力力是原创柯基矢量形象，包含白色额纹、短腿、大耳朵和绿色项圈；轻微眨眼和点头支持减少动态效果的系统偏好。人格定位为温暖、简洁且重视证据的高中实验伙伴。

教学顺序：预测 → 控制变量 → 记录 → 图像比较 → 解释与反思。力力可以说明公式，但不得编造学生做过的操作和读数，不给学生自动贴能力标签。模型数值在服务端依据允许范围内的参数重新计算，客户端提交的伪造模型结果不作为依据。

提问明确指向位置区间速度、质量倒数或时间平方时，力力先选择对应关系，再裁剪要讨论的条件组；缺少数据时给出该关系实际需要的采样数量与控制条件。自动采样最多附带最近30条保存的参数和时刻，由服务端重算分析；手动虚拟读数最多10条，继续按原操作读数算术重算。回复区分位置派生速度与模型瞬时速度，不把两者或手动读数混称真实实测。当前无飞行段、牛二尚未启动或保留了旧条件记录时，引导应说明边界，而不是布置当前装置无法完成的对照。

访客、演示、教师入口或过期档案使用“本地引导”；选择有效学生账号档案后可请求联网帮助，未配置 AI 或联网失败时明确降级，联网回复显示“AI 回复”。AI 配置、会话命名空间、工作目录与初中光光独立，档案或会话身份变化时清空旧会话、取消等待并使旧上下文失效，不借用另一个入口残留的登录状态。助手的聊天不是实验记录，不宣称自动存入学校档案。

## 模型取舍

| 实验 | 重点 | 保留的边界 |
| --- | --- | --- |
| 匀变速运动 | 有符号位置、速度、恒加速度与位置区间分析 | 一维质点；区间中点关系仅适用于匀变速，实际计时器操作待扩展 |
| 共点力合成 | 共点矢量和、独立试配、残差与夹角关系 | 几何模型，不模拟橡皮条或测力计；零合力无方向，零分力无夹角 |
| 弹簧 | 静态载荷、原长与伸长、F–x关系 | 轻弹簧，预设线性范围0–0.25m；无振荡、塑性或滞回，不能测定真实弹性限度；尚无手动读尺 |
| 牛顿第二定律 | 系统总质量、阻力、绳张力与两类控制变量对照 | 理想滑轮、轻绳；静止时T=mg，启动后不能把mg当绳张力；不模拟端点碰撞 |
| 平抛与斜抛 | 水平与竖直分运动、下落距离与首次落地 | 无空气阻力；平抛设零抛射角；初速为零时为自由下落，斜抛不直接套(h₀−y)–t²直线 |
| 单摆 | 非线性摆动、周期和能量 | 无阻尼，摆长到球心；不把大摆角当小角近似 |
| 电动势与内阻 | 负载工作点、U–I 关系 | 理想电表，暂不模拟电池温升和放电 |
| 双缝干涉 | 几何光程差、屏幕光强与近轴间距 | 两相干点源；暂无单缝包络 |

计算依据和数值方法见 [物理模型说明](../../packages/physics/src/highSchool/README.md)，课程核对见 [课程映射](CURRICULUM_MAP.md)，开源采纳见 [GitHub 参考](OPEN_SOURCE_REFERENCES.md)。

## 第二十四阶段：其余十四项

新增器材控制使用明确中文功能、量程和接法，整数匝数/滴数按整数校验。无效接法、超量程、未夹持等状态不能保存为有效读数，未定义的周期、半径与折射角使用状态说明。万用表的历史和CSV按读数项目与单位分别建列，不把电压、电流、电阻混为一列。

变压器动画每墙钟秒演示一个周期，模型和档案仍使用真实频率对应的物理秒。精密尺另提供主尺、辅助尺与零点自主填写和核对，本页练习不自动保存到模型档案、课堂或力力。原有独立手动档案保持原来源与权限。

新增分析包含向心力的三种单变量关系、碰撞前后动量与恢复系数平方、金属丝R—L及U—I、折射正弦、感应电动势—负磁通变化率、变压器有效值、传感器温差对数、油膜厚度—面积倒数、气压—体积倒数、自由落体位移—时间平方、光电遏止电压和磁场轨迹半径等。拟合采用保存读数与当时条件，不重新生成数值覆盖原记录；至少三种不同横坐标并按控制条件分组，无法应用的记录明确排除。
