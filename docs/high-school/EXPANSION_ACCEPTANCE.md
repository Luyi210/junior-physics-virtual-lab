## 逐项验收要求

| 实验 | 必须覆盖的关键边界 |
| --- | --- |
| 向心力 | 固定ω与固定v不能混淆；零转速无周期，力向内、速度切向。 |
| 精密长度 | 主尺/辅助尺可读；分辨率与零误差修正；量程和仪器切换有效。 |
| 电阻率 | 长度与直径单位转换、面积平方、U/I关系、固定材料控制变量。 |
| 多用电表 | 功能/量程/接法有明确选择；错误接法或超量程不能保存为有效数值。 |
| 动量守恒 | 先判定是否真实发生碰撞；方向有符号，动量守恒，恢复系数决定能量变化。 |
| 折射率 | 角度从法线量起；正入射、临界角和全反射不伪造折射角。 |
| 感应电流 | Φ与−NdΦ/dt同一几何模型；正方向约定与电流标记一致。 |
| 变压器 | 使用交流有效值、匝比和功率关系；不把理想模型当作直流变压。 |
| 传感器 | 一阶温度响应、线性电压与滞回输出同源；起止温度与初态完整保存。 |
| 油膜 | 浓度、滴数、体积与面积单位可追溯；V/S仅为单分子层估算模型。 |
| 气体 | 恒温与密闭条件、绝对温度和绝对压强；V与1/V关系不混用。 |
| 自由落体 | 初始条件和方向明确；到地面前截止，不伪造落地后运动。 |
| 光电效应 | 频率阈值、光强与遏止电压作用分清；低于阈值不因增强光强而出射。 |
| 带电粒子 | 电荷符号/磁场方向决定弯曲；零场直线边界，速度方向和力同源。 |
