# 第十四阶段：高中课堂任务与报告

日期：2026-11-11。本阶段把已开放的7项高中实验接入教师备课、学生任务与既有四段实验报告。保留本机自由探究档案及现有学校数据，没有数据库迁移，也没有把文字报告改称原始读数附件。

## 可体验的流程

1. 教师登录，在备课模板中选择“高中”的开放实验，填写或修改默认问题、控变量、证据与反思，再发布到自己的班级。创建班级支持高一、高二、高三。
2. 学生从任务中心开始实验；明确的任务和会话参数跟随路由。工作台核对学生、学校、实验、任务及会话后显示课堂说明和报告入口。自由入口不继承其他实验的活动任务。
3. 学生在实验中保存本机读数，进入课堂报告，选择本次任务需要的记录。默认不勾选；同实验以前的自由探究记录可能也在列表中，由学生明确选择。
4. 查看完整文字预览，再确认加入“测量数据与观察”。原文保留；选中的ID、UTC时间、仿真时刻、参数、数值和单位全部保留。手动虚拟仪器另外保留起止/坐标、计数、分辨率、假设与复核提示。
5. 既有报告队列先存本机、再保存到账号。保存状态以页面实际结果为准；任课教师在报告页查看四段文字。完成会话后报告只读，允许重试的任务会创建独立新会话。

任务关闭后课例说明接口可能返回404；只要学生归属已验证，历史报告入口仍可进入。其他鉴权、网络和服务错误不伪装成正常加载。

## 数据与身份边界

- 预览和确认都检查完整来源，不按力力最近30条自动/10条手动限制裁剪。超过12000字符拒绝追加，不覆盖旧正文或截断所选记录。
- 只读取当前学生v3正常档案。游客、教师、过期身份、旧公共档案、待恢复副本和无法校验的手动读数不转存；读取或保存异常时先返回工作台处理，不用最后一次缓存冒充当前档案。
- 确认前后核对当前身份、scope修订、真实后台会话、报告版本、原正文和完整预览内容。身份切换、卸载、正文改动、源记录更改、已完成或版本差异会阻止旧预览追加。
- 自动读数保留原保存值，只核结构、单位、参数和时窗，不拿当前理论值替换历史数字；手动记录核对原始读数及推导算术，保留历史提示。
- 加入的是可编辑文字副本，不是不可篡改证据、自动同步的仪器档案或老师已认可的结论。完成会话仍允许四段报告为空，没有新增提交审核、评分或教师反馈状态。
- 另修复报告冲突处理的旧回调：等待读取账号版本期间切换学生、退出、换令牌/后台或卸载，不再用迟到响应清掉原学生待同步草稿。

## 后台与已有初中流程

共享课堂目录提供21个初中入口与7个开放高中入口，供教师选课、任务跳转、后台创建校验使用。保留初中路径中的module/mode参数。新建课例、任务和会话拒绝未知/筹备实验；历史未知实验记录继续可读，已存在活动会话可恢复和完成，不删除旧数据。

教师创建任务和更新状态限制为本人创建的班级，同校管理员保留管理权限。既有同校任务列表读取范围未改变；报告读取继续按学生本人、班级创建教师或同校管理员校验。

并发首次开始曾产生两份会话，已修复：同进程按数据库/任务/学生排队；SQLite使用单条条件插入，同时检查活动会话和不允许重试时的已完成会话；PostgreSQL事务先锁定任务行，再重读并创建。没有新增唯一约束或清理历史重复行。真实SQLite两个独立连接竞争通过；pg-mem只能验证语句兼容与锁调用次序，真实PostgreSQL多进程仍待验收。

初中助手自动事件现在要求明确匹配的初中课堂URL及任务/会话，不能因为残留活动高中会话而把自由探究事件误记入高中报告。旧高中/未知会话队列保留、不补传；初中离线事件不再被500条截断，每批最多500，成功后只移除确认发送ID，期间新增的事件和其他会话继续保留。
