# 第二十八阶段：增强观测站的空间感

日期：2026-11-11（Asia/Shanghai）。在[第二十七阶段](STAGE_27_COSMIC_DESIGN.md)深空配色的基础上，回应用户“更佳科技感”的反馈，扩大场景、强化体积与光迹，并增加可操作的展开观测。

## 本轮变化

- 首页以更大的观测舱为主视觉，补充静态参考刻线、分区光感和器材展示台面。课程卡只在悬停或键盘聚焦时轻微抬起，不为24张卡常驻动画循环；减少动态时关闭位移动效。
- 天体画面增强球面明暗、大气亮边、轨道光带和卫星短尾迹；干涉画面强化起伏波面的透视；量子云增加双叶密度和体积光。背景星云缓慢变化，量子画面仍不绘制经典电子轨道。
- “展开观测”在页面内放大场景并显示水平/俯仰滑块，支持原生键盘调节；Escape收起并返回展开按钮焦点。显示的角度来自手动视角，不是物理测量值。展开不会启动正式实验、写档案或改变实验时钟。
- 头部、工作台与参数区统一仪器边框和局部亮边；时间与主要读数采用凹入式深色数字仪表。装置视口保留浅色二维测量面。三维共用环境增加弱青色补光，调整台面反射和参考网格，器材几何、相机与额外阴影预算不变。
- 力力面板采用终端式标题条、静态头像环和凹入输入框；发送按钮扩大到40px。新增思考指示只在真实busy状态存在，运行光效只在已有实验时钟运行时生效。

## 代码边界

全部改动位于 `apps/web/src/features/high-school/`。首页布局在 `pages/HighSchoolHomePage.tsx` 与 `HighSchoolHome.css`；仪表主题继续放在 `styles/HighSchoolTheme.css`、`pages/HighSchoolWorkbench.css` 与 `assistant/LiliCosmicTheme.css`，没有另建第二套全局主题。

宇宙模块在 `components/cosmos/`。本轮将静态画面从组件主体拆到 `CosmicStaticArt.tsx`，投影、轨道分段及绘制尺寸约束放在 `cosmicGeometry.ts`，Canvas绘图在 `cosmicPainter.ts`，原 `cosmicLoop.ts` 仍管理动画生命周期。主组件负责输入、展开状态和浏览器观察器；SVG降级与Canvas使用相同的几何辅助函数。

保持最多30次绘制/秒、DPR不超过1.5，并增加Canvas背板宽度1600px上限；视口变宽不会无限增加绘制像素。隐藏、离屏、暂停、减少动态与卸载清理规则继续有效。手动操作更新角度状态，动画帧不逐帧更新React。

本轮未引入依赖、远端纹理、Bloom后处理或新的物理模型。继续采用[上一轮核查的开源视觉参考](OPEN_SOURCE_REFERENCES.md#第二十七阶段宇宙视觉与空间界面)，没有重新宣称上游维护状态，也没有复制外部资源。后端、数据库与既有教学记录未改动，没有发布上线。
