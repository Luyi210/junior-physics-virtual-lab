# 第二阶段：从采样到分析

日期：2026-11-11。延续第一阶段本地开发，尚未发布。浏览器因锁屏/窗口与host不可用，视觉及真实触控仍待验。

## 实现

`packages/physics/src/highSchool/measurementAnalysis.ts` 独立分析保存的模型采样，不调用当前模型补造缺失历史。每条记录保留参数与单位；不同控制条件分组，重复横坐标先取均值，至少3个不同取值才拟合。非法、缺失单位、重复编号、落地后采样、数值退化记录给出排除或不足原因，原记录不删除。

支持 v–t估计加速度；固定系统总质量的a–F；抛体x–t和vy–t；小角单摆T²–L；固定E/r的U–I；双缝近轴间距–屏距。单摆大角不反推g，常量/近常量纵坐标的R²无定义。双缝间距来源于模型公式，界面明确其不是独立波长测量。

独立分析面板支持选择关系及条件组，显示原记录序号、散点、拟合线、带单位估计值、均方根残差、边界与下一步。物理计算不在React组件重复实现。

力力只接收最近最多30条本机仿真参数与时刻，在服务端重算后分析，忽略客户端伪造的指标或拟合。回复说明采样窗口和模型来源，不把拟合一致当作真实精度。缺失完整历史参数、重复编号、超范围或超过30条均拒绝。询问自己的数据不会再因“我测到”三个字被误当成请求编造。

数值输入保留负号、小数与清空等编辑态，Enter/失焦提交，Esc恢复。修复页内跳转改写HashRouter主路由的问题。
