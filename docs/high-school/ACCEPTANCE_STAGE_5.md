# 第五阶段：让力力按手动记录给提示

日期：2026-11-11。本地开发，未发布；真实上游AI与实际浏览器仍未验收。

## 从页面到服务

手动档案变化通过独立回调传到高中工作台，最近10条按白名单映射为上下文。仅发送编号、仪器类型、当时完整参数、原始读数和时刻，不发送存储中的派生指标/说明。清空、同数量替换和实验切换会更新上下文；只有学生点击提问或提交问题才发请求。界面显示可引用条数及“看看我的手动读数”入口。

后台独立校验 `manualRecordCount/manualSamples`：实验与仪器类型对应、编号不重复、总数与窗口合法、参数完整有限且在范围内、原始读数按显示分辨率记录、计时结束与保存时刻一致。单摆限制60s观察窗，双缝稳态时刻为0。无手动字段的旧请求保持兼容。

白名单资料放入 `manualInstrumentReadings`，与自动模型采样 `savedSimulationAnalysis` 分开。只按用户保存的原始读数计算T、近似g、条纹间距与近轴波长，不用理论值回填。客户端伪造的计算结果或文字不进入可信资料。

## 教学行为

- 10s手动区间、4个周期仍得到T=2.5s，不替换成理论周期。
- 已知波长550nm，但手动坐标±2.4mm、4间隔、d=.5mm、L=1m时，仍讨论按读数算出的600nm。
- 当前角度改成5°，旧记录为60°时仍依据旧记录拒绝小角g估计。
- 自动采样与手动读数同时存在，模糊的“分析记录”会先区分来源；明确问自动分析则继续既有拟合路径。
- 单摆周期与同条件模型相差超过25%时，保留原始数值并置顶提示复核，不把异常g当有效估计。这个阈值只用于提醒；未触发不代表计数/起止正确。
- 本地引导能解释计时、间隔数及定位偏差，不凭数量断言完成、不把虚拟读数当实体实测、不代写或伪造记录。
