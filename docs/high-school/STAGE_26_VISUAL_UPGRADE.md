# 第二十六阶段：高中界面与动态展台

日期：2026-11-11（Asia/Shanghai）。本轮回应“高中界面不如初中有质感、动态不足”，只升级本地高中前端。

## 已实现

- 首页采用深海蓝实验展台、暖纸色目录、铜金器材和青绿轨迹；课程卡按领域区分，保留24个入口、搜索、册别筛选、档案身份和教材来源。
- 展台可切换单摆、抛体和碰撞，可更改摆长、抛射角或恢复系数，支持暂停、重放和进入对应实验。坐标和读数调用现有纯物理函数；SVG提供示意深度，不能旋转，不冒充WebGL三维场景。
- 单摆观察8秒、碰撞观察6秒、抛体到落地停止；抛体明确标注0.5倍慢放。最多每秒30次React更新，页面隐藏或展台离屏暂停推进，不补算离开期间的时间。减少动态效果偏好默认静态，仍可主动播放。
- 工作台突出装置、控制和主要读数，增加真实实验时钟驱动的进度与运行状态，稳态实验不显示虚假播放进度。探究步骤可展开，装置、图像、记录之间可滚动并转移键盘焦点。
- 三维共用器材区分涂装、金属和木材，采用暖主光、冷补光与柔和地面；保持原几何、坐标、相机控制和按需渲染。没有新增后处理、外部贴图或常驻三维动画循环。
- 高中主题局部覆盖旧全局字体令牌，标题、正文和读数分别使用衬线、系统无衬线与等宽字体；数字输入的错误态保留。
