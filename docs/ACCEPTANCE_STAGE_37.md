# 第三十七阶段：光光与力力的分步实验辅导

日期：2026-11-12（Asia/Shanghai）。用户暂停腾讯云配置，选择优先改善“看懂操作、指出问题、分步提示”。本轮完成本地代码与自动验收，未部署或调用付费模型。

## 学生可以使用的变化

- 两位助手都有三级入口：观察方向、操作方法、证据自检。可依次查看，也可直接选一级；显示的是上次查看级别，不是完成度或掌握度。
- 力力的24项高中实验都有对应预测问题、控变量建议和证据自检。显式“给我一级/二级/三级提示”即时使用本地引导，登录后也不等待网络或向在线模型展开完整答案；API入口同样保留此行为。
- 力力先检查当前条件：双缝只有中央亮纹、单摆大摆角、碰撞尚未发生、测量接法无效、全反射、零场、零光功率、零合力等。无效占位值不能作为测量证据；零值对照保留，方向或夹角未定义时不要求猜测。
- 光光回复保存提问时的有界装置摘要，可展开查看来源与时间；即使参数先改动再改回，也会说明等待期间曾变化。可以点击“按现在的装置再问”。
- 光光可以停止等待；普通联网问题30秒未完成时转本地引导。切换实验、离开页面或切换身份后，旧请求不能追加回复或清除新请求的等待状态。
- 光光快速离开再返回时，优先读取待保存的最新会话，避免延迟保存前丢失已完成对话。同一实验仅改变查询参数或打开对话，不再取消正在进行的提问。
- 力力推荐问题与上次提示级别只取当前实验的回复；历史回答仍带各自提问条件，不会伪装为当前装置的判断。
