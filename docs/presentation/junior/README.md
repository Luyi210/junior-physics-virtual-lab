## 史实口径

- 2026-07-20 是仓库中可核验的首版提交；更早的构想与完整对话无记录，不作细节推断。
- 2026-07-21 的开源参考目录证明当时下载和整理了仓库及阅读重点，不证明所有项目在首版制作前已学完。PhET 的模型和视图分离思想在首版 README 中有明确记录。
- “36 个实验节点”来自后续参赛设计说明；当前课堂可分配注册表的“21 个初中入口”是另一种统计口径。它们不能互换。
- 封面是当前本地网页截图，不是首版历史截图。设计说明中的桌面封装和教学效果目标也不能直接理解为现在已经公开部署或经过真实课堂验证。
