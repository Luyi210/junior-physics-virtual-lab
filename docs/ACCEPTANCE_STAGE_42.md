# 第四十二阶段：试用前流程检查与阻断点修复

日期：2026-11-12（Asia/Shanghai）。本轮沿“进入实验 → 操作 → 向助手提问 → 保存 → 重新查看”的路径检查本地产品，优先修复影响手机试用的阻断点。服务器配置继续暂缓。

## 实际发现与处理

- **助手等待与来源。** 力力的请求可能在取消信号发出后仍一直等待，现设超时竞速，恢复输入并提供本地答案；迟到的联网结果不覆盖当前实验。光光、力力均对空白或损坏的线上回复回退到本地引导；未核实线上服务时清楚标示“联网待验证”。
- **初中记录本与登录。** 未保存的手写草稿按实验暂存，在同一标签页切换实验、刷新或重新进入时可恢复；关闭标签页前仍需点击保存。写入本机失败时提示用户并保留当前页面文字；损坏的本机记录不会被静默覆盖。自动观察按本次会话的事件关联，避免挂到另一轮实验。云端统计只随当前学生身份更新，手机登录防止重复提交。界面明确区分此浏览器共用的自由探索记录和学生账号档案。
- **高中记录链路。** 为目录入口、手机默认二维后的参数与时钟操作、模型记录保存／重开、单摆手动读数保存／重开，以及力力拿到当前实验快照的流程增加组件测试。代表实验覆盖单摆、力的合成和电动势与内阻；其余实验仍沿用已有的逐项二维渲染测试。本轮没有发现需改动高中物理模型的确定问题。
- **本机上线自检。** 演示服务的入口检查增加高中目录和上述三个实验直达页，避免发布包只测初中入口。
