# 第三十八阶段：连续追问与当前实验排障

日期：2026-11-12（Asia/Shanghai）。本轮按用户要求继续提高光光、力力的实验辅导能力，完成本地实现、回归测试和生产构建。服务器配置继续暂停，未部署、未新增模型供应商、未调用付费模型。

## 学生可以使用的变化

- **接住短追问**：同一实验中，助手使用最近三轮已完成问答理解“为什么”“没看懂”“下一步呢”“再给一点提示”。没有明确前文时请求补充，不猜测学生指代；明确的新问题优先。
- **按现在的条件排障**：新增检查当前实验入口，也可直接问“现在呢”“这样可以吗”。光光读取装置快照、页面提示及读数来源；力力重新检查本次条件和已有模型限制。没有发现已知阻碍，不等于所有操作正确、实验完成或结论成立。
- **提示可以继续推进**：相对提示衔接已有级别，最高停在第三级。界面显示学生原话，临时上下文保存解析后的话题或级别，连续多次短追问不会仅因原问题超出三轮窗口而丢失话题。
- **参数变化后重新判断**：旧回答保留提问时条件与变化提醒，新回复使用本次状态。光光发现相邻快照多个控制量改变时，提示核对控制变量，不直接认定学生操作错误。
- **对话上下文的范围**：取消、未完成的问题不作为完整问答；光光切实验、离开页面或切身份会清理临时上下文。力力在此阶段按实验筛选近期问答，但返回旧实验仍可能取回旧话题；这一缺口已在[第三十九阶段](ACCEPTANCE_STAGE_39.md)补上访问隔离与取消处理，旧回复仅保留为带原条件的显示历史。

光光的“下一步呢”结合当前装置给下一小步；“再给一点提示”递进提示级别。力力这两类短追问都接入分级引导。两者均保留直接选一级、二级、三级的入口。

前端近期问答是帮助理解话题的线索，不能作为可信测量证据或覆盖当前物理计算。API 对历史进行裁剪或校验，并转义进入提示词的内容。两位学生助手每次在线请求使用新的底层模型会话，仅由显式有界上下文衔接；运行时仍复用。教师助手保留原有会话方式。

光光临时上下文不从旧本机显示历史重建；当前窗口之前的事件和观察也不自动加入学生请求。这不代表已经迁移初中全部本机历史的账号归属，旧显示历史仍沿用既有设备/领域存储。

原文件备份在 `.runtime/stage38/baseline/`。既有工作区其他改动保留。

## 实际 Edge 操作验证

在本机预览 `http://127.0.0.1:5174/#/high-school/experiments/multimeter` 中，通过原生 Edge 界面实际操作并读取页面状态：

1. 打开力力，看到检查当前实验入口和三级提示；默认电压测量条件下检查，回复保留“未发现已知阻碍不等于实验完成”的限定。
2. 将电表切到电流挡，保留原有并联接法；页面显示接法无效、记录按钮不可用。
3. 输入“现在呢”，力力指出当前接法或通电条件无效，并给出电压并联、电流串联等检查方向。
4. 改为“串入电流回路”，页面显示 6.00 mA、记录按钮恢复；再问“现在呢”，力力重新判断当前条件，旧回复仍显示条件变化提醒。

没有点击保存实验记录，也没有新增业务库实验数据。此项验证证明力力的一条真实排障流程能够衔接操作变化，不代表全 24 项高中实验的所有交互已经实机覆盖。

随后尝试进入光光页面时，地址栏与实际页面内容持续不同步，未取得有效的光光实机验收结果；截图通道还曾返回空白画面。因此完整桌面排版、光光实机、手机触屏及 GPU 效果仍待验收，不能由组件测试代替。

## 后续限制

- 助手读取应用提供的控件、装置状态和记录，不是摄像头或视频视觉识别。当前检查和光光短追问本地完成；力力分级提示与当前检查本地完成，普通解释沿用既有联网/本地回退链路。
- 短追问覆盖明确的常见表达及已支持话题；指代不清时澄清，不承诺理解任意长对话。
- 没有代替学生生成实测数据、认定完成度或评分；没有修改实验物理计算模型。当前诊断不声称穷尽所有参数组合。
- 腾讯云上传、安装、服务启动及公开测试入口尚未进行；没有修改 DNS、防火墙或已有相辉网站。Stage35 发布包不含本轮改动，恢复部署前需要重新打包和验证。
