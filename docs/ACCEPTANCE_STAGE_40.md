# 第四十阶段：手机布局、触控与助手输入

日期：2026-11-12（Asia/Shanghai）。本轮按用户要求优化手机网站，覆盖首页、初中探索、高中实验、学生记录、两位助手及教师导航。已完成本地实现与自动检查；真实手机验收尚未完成。

## 已实现

- **手机入口与阅读。** 首页顶部恢复初中／高中／教师入口；高中压缩标题、档案与导航留白。学生搜索、登录、记录、实验参数、两位助手及教师表单的手机输入采用 16px，修复旧全局 `14px !important` 和力力横屏字体覆盖。调整主要按钮、滑条、场景切换热区，补充安全区及横屏规则；没有禁止页面缩放。
- **小屏实验画布。** 凸透镜 Canvas 不再强制至少 540px，按实际容器绘制，并扩大物体／光屏拖动热区。小孔实验允许纵向翻页，取消手势或仅触碰不记作有效拖动。黑洞使用 SVG 坐标换算，避免窄屏留白引起的拖动偏差。
- **触摸与滚动分开。** 初高中三维与黑洞交互提供显式启用／退出，默认允许页面滑动。高中力合成只有箭头端点接管拖动。单摆手机释放角按钮从三维投影内移到画布下方，保留同一参数回调与完整刻度位置；减少密集的半米文字标签。初高中三维容器隔离层级，防止三维标签遮住聊天。
- **聊天与软键盘。** 光光、力力复用可见视口 hook，按键盘上方的可见区域定位；仅打开时订阅事件，合并同帧更新并清理监听。手机正文独立滚动、输入时减少辅助内容，打开只聚焦面板，关闭归还入口焦点。光光修复中文输入法确认回车误发送。双指放大时不缩小面板抵消缩放。
- **渲染开销。** 高中手机三维像素比上限 1.25、关闭阴影；首页减少动态模式不轮播，暂停或静态预览仍能显示图像。保留三维模型及原物理计算。尚无真实手机帧率测量。
- **教师手机导航。** 增加收起遮罩、展开状态和 Escape 关闭，侧栏按动态视口滚动，调整输入和按钮尺寸。
