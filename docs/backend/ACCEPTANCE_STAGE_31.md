日期：2026-11-11（Asia/Shanghai）。用户确认物理平台与相辉学堂是两个产品，共用腾讯云主机；物理平台尚未选择独立域名。此阶段完成本地部署准备，不代表生产上线。

## 已完成的本地改动

- `scripts/serve-render.mjs` 接受显式 `PHYSICS_WEB_HOST`，便于内部测试只监听 `127.0.0.1`；未设置时保留原有 `0.0.0.0` 默认，内部 API 继续固定回环。
- `scripts/lib/api-proxy-timeout.mjs` 为 `/api/lili/chat` 及其单个尾斜线形式按后台有效超时增加5秒余量，默认50秒、最高125秒；普通 API 保持15秒、原光光路径保持165秒。浏览器原有50秒等待未改，管理员提高后台限额不会自动延长浏览器等待。
- `deploy/linux/` 包含独立 systemd、环境示例、启动前只读检查、合成配置测试和全注释 Nginx 示例。单独的运行账号、版本目录、SQLite、配置与备份位置及恢复权限要求见[部署说明](INDEPENDENT_SERVER_DEPLOYMENT.md)。
- 配置示例关闭演示 seed、付费 AI 和外部向量服务，凭据留空/占位，缺少已复核标记或有效配置无法直接启动。候选端口18080、18787仍待目标机确认；Nginx示例尚未启用，不使用相辉域名及其子域。
