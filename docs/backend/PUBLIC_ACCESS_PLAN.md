# 物理实验平台：从内部部署到扫码使用

规划日期：2026-11-12（Asia/Shanghai）。用户不记得服务器密码，希望由我们规划接入方式，最终让访客扫码打开网站即可使用。本文件是实施顺序与验收标准，不代表网站已经部署或公开。

## 推荐方案

- 管理入口：已通过用户登录的腾讯云控制台 Edge 页面操作“文件管理”和“执行命令”，无需向聊天提供服务器密码。电脑控制工具此前曾拒绝该页面，本次可用状态以实际操作结果为准；电脑锁屏或用户切换标签页时可能中断控制。也可采用经授权的 SSH 或官方 API。不自动重置密码或更换密钥。[腾讯云登录说明](https://cloud.tencent.com/document/product/1207/44642)。
- 托管方式：继续使用现有腾讯云服务器，物理平台拥有独立服务账号、目录、数据库、配置、备份和站点。两个产品仍共享 CPU、内存、磁盘、网络和主机故障风险；需要实测容量并设置适当资源约束，不能承诺完全互不影响。
- 网站地址：已选 `physics.xianghuiacademy.cn` 作为物理平台专用子域名；尚未核实 DNS 管理权、备案接入与证书条件，也未创建 DNS 记录或启用网站。若后续品牌需要独立主域名，可以再迁移；当前不必先购买新域名。
- 访客体验：公开后扫码打开 HTTPS 网站，选择初中或高中实验，直接开始操作。账号用于需要身份的课堂、作业和记录管理；访客不需要腾讯云账号或服务器密码。

第一阶段已通过腾讯云控制台完成，不依赖本机 SSH 密码；Stage44 包已由文件管理上传，并在服务器核对摘要与 733 个源码文件。内部服务不开放公网端口，因此手机扫码验收要等第三阶段，不能把 `127.0.0.1` 或本机开发网址做成对外二维码。

服务器位于中国大陆时，对外解析和提供网站服务前须核实 ICP 备案与腾讯云接入状态。腾讯云说明，已在腾讯云备案的二级域名对应的三级域名一般无需单独备案；但现有备案服务名对应另一产品，须核对物理平台内容是否与备案信息相符、是否需要办理网站信息变更。测试阶段也不自动豁免这些要求；核验结果尚未取得。[腾讯云备案场景](https://cloud.tencent.com/document/product/243/19630)、[备案信息变更与服务名称](https://cloud.tencent.com/document/product/243/73180)

## 产品验收重点

1. **扫码即用**：检查匿名访问初中、高中目录和实验全过程，避免将教师/学生登录页面设为所有访客的必经入口。
2. **记录说明准确**：现有高中实验档案主要保存在当前浏览器，登录后按账号区分本机档案，不等于自动同步学校后台；云端实验记录同步列为后续事项。明确本机记录与服务器课堂记录的差别，不宣称匿名或登录后的本机记录会自动跨设备同步。换域名时处理旧地址和本机存储迁移，不能只更换二维码。
3. **手机和物理正确性**：覆盖代表性力学、电学、光学实验的触屏操作、参数边界、单位、重置与读数；低性能或不支持 WebGL 的设备仍可使用二维模式。桌面构建及自动测试通过不能代替手机实测。
4. **力力的功能与成本**：第一版先验收现有本地引导；联网 AI 另行配置服务端凭据、调用额度和故障提示后启用，当前部署模板仍关闭付费 AI 调用。
5. **持续运行**：落实数据库定时备份并实际恢复一次，检查服务异常重启、日志、资源余量和现有产品；以后每次升级保留版本包与升级前备份。

正式二维码只保存稳定网站地址，不包含管理员令牌、密码、临时登录凭据或服务器管理链接。后续更新网站内容通常无需更换二维码；若更换域名，需保留旧地址跳转和相应域名/证书维护，或重新分发二维码。
