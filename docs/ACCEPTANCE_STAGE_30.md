# 第三十阶段：网站操作与异常恢复修复

日期：2026-11-11（Asia/Shanghai）。本轮根据用户要求检查网站 Bug，修改仅在本地，未部署。保留已有未提交代码、账号和课堂数据库。

## 已修复的问题

| 入口 | 原问题 | 本轮结果 |
| --- | --- | --- |
| 学生首页、课本图鉴、任务中心 | 页内 `#fields` 等链接覆盖 HashRouter 的页面地址，点击后回到平台首页 | 页内按钮滚动到目标区域并保留路由；尊重减少动态偏好 |
| 学生身份检查 | 账号 A 的旧请求迟到成功或失败，可能覆盖或退出后来登录的账号 B | 根据学生归属、请求序号和页面生命周期核对结果；登录、退出、游客选择及卸载作废旧检查 |
| 教师创建账号 | 账号创建成功后分班失败，界面仍让教师重新创建同一账号 | 保留已确认的账号，刷新账号列表；独立重试分班或刷新，不再重复创建，也不保留表单密码 |
| 机械能图表 | 两个图像使用相同纵轴字段作标识，第四张“动能增加—势能减少”实际选回第一张时间曲线 | 按横纵轴组合区分图像，选中状态、横轴与当前点同步正确 |
| 力力机械能手动档案 | 已有手动读数上下文，但没有显示数量和“看看我的手动读数”入口 | 补齐机械能手动读数提示与入口，沿用已有上下文和发送逻辑 |
| 实时麦克风 | 取消或离开页面后，迟到的权限结果仍可能启动采集；音频初始化失败时资源释放不完整 | 每次请求独立管理资源，请求中可取消，迟到结果立即释放；失败与卸载清理轨道、音频节点和上下文 |
| 麦克风操作记录 | 通用按钮在权限请求、取消和失败前就把操作记录为“启动” | 仅真实采集或模拟信号成功启动时记录运行；取消和拒绝不会产生虚假启动证据 |
| 麦克风波形区 | 波形的 SVG 尺寸规则误作用于提示里的小图标，导致图标巨大、文字竖排 | 波形尺寸样式仅作用于直接子 SVG，提示图标恢复自身尺寸 |
| 页面使用引导 | 浏览器拒绝存储读取时页面异常，写入失败时引导无法关闭 | 存储偏好失败不阻断页面，引导仍可关闭和重新打开 |
| 教师本地演示 | 演示学生人数误标成“真实后台学生” | 根据实际模式标明“本地演示学生”或“真实后台学生” |
| 浏览器标签图标 | 未设置图标，浏览器请求 favicon.ico 返回 404 | 加入与原子品牌标志一致的 SVG 图标，使用 Vite 基础路径支持子目录发布 |
