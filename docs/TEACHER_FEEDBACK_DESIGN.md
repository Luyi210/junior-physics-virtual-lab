# 教师反馈与学生修订

状态：第十八阶段提出方案，第十九阶段已实现反馈接口、独立表及教师/学生页面，自动验收见[第十九阶段记录](ACCEPTANCE_STAGE_19.md)。教师先核对学生已保存的四段报告，再提交文字反馈；学生按需读取并查看被评版本的原文。“完成实验”仍使原会话报告只读，已完成报告修订及关联反馈的重做尚未实现。

## 学生与教师应看到什么

教师阅读学生自己保存的预测、测量与观察、结论、疑问后，写一条具体反馈，例如“你保持了哪个变量不变？请把两组读数写进结论”。反馈显示作者、时间以及当时查看的报告版本。它不自动生成分数、能力标签或“已达标”结论，也不替学生改写正文。

学生能查看该反馈对应的原报告和自己当前的报告，知道老师评价的是哪一次提交。未结束的会话继续使用现有报告编辑器和版本冲突流程；学生自己决定如何修改。反馈的创建不会改学生报告版本或结束会话。

## 必须保存的关联

反馈采用独立、追加式记录，至少包含学校、班级、任务、会话、学习者、教师、反馈正文、创建时间、所评报告版本和当时四段正文快照。不能只存版本号：当前 `session_learning_records` 只有最新正文，没有可回查的历史版本表。

客户端提交拟反馈的会话、期望报告版本和唯一操作编号，服务器通过一条原子条件INSERT重新确认归属、当前正文与版本，并复制快照，避免共享SQLite连接在多次await之间混入其他事务操作。新操作在读取时已发现报告更新，拒绝基于旧预览发布并要求教师重新阅读；并发先后以数据库语句的有效快照为准。网络重试复用原操作编号，不生成两份反馈。同一作者、会话、编号配不同正文或版本返回冲突；完全相同的旧操作即使报告后来已更新仍返回原反馈。

目前没有覆盖、删除或更正关联接口。如需正式更正，应后续增加明确关联原反馈的追加记录；不能把再次提交普通反馈当作已建立更正关系。撤回、保留期限、批量导出和评分也未实现。

## 权限与并发

- 任课班级的创建教师或同校管理员可以阅读并反馈；其他同校教师、其他学校用户不能操作。客户端过滤不能替代服务端检查。
- 学生只能读取自己的反馈，不能以自报的姓名、角色或学校改变归属。服务端从真实会话与登录用户读取这些字段。
- 反馈请求、页面草稿和迟到响应绑定教师通道的学校、用户及登录代次；不使用高中自由档案的教师/学生选择器来决定反馈身份。
- 已经发往后台的请求可能在切换账号后完成。前端应丢弃迟到结果，并允许原作者随后核对实际状态，不能把界面离开描述为“已撤销发送”。
- 学生编辑与教师反馈使用不同版本号；新增反馈不让学生当前草稿产生无关冲突，也不清除其未同步文字。

## 已结束会话的处理

不通过反馈把 `completed` 改回 `active`。原实验的时间、记录和证据继续只读。

既有任务仍按`allowRetry`与开放时间决定能否另开实验尝试。本轮没有新增从反馈开启重做的入口，也没有给普通重做自动添加来源关联。若后续增加“依据反馈再做一次”，新尝试应关联来源会话/反馈，报告保持独立，不自动复制旧结论。若要在“禁止重做”任务中仍允许修改完成后的文字报告，则需要独立的报告修订实体与教师发布规则，不能绕过现有任务限制。

## 页面中的草稿与版本

教师明确打开某份档案的反馈面板才发起读取，不为所有折叠卡片批量请求。编写依据显示版本和完整四段原文；冲突后保留草稿，刷新得到的新正文需要点击“已重新核对，改用此版本”后才能再次提交。显示最新已读取账号版本与选择作为反馈依据的版本是两件事，不静默改变提交依据。

未提交正文和结果未确认的提交仅存在当前标签内存，按教师账号、后台、学校及完整会话归属隔离。收起、切任务或同账号续签后可继续，换号隐藏原草稿；刷新、关闭标签会丢失，有beforeunload提醒，但该提醒不保证所有浏览器都会显示。未知发送结果保留原正文、版本和编号，锁定编辑并提供原操作重试；确定冲突才转为重新核对流程。没有自动写入localStorage或云端草稿，也不宣称任意并列挂载的同会话编辑器具备共享事务协议。

学生点击读取反馈后，查看作者、时间、版本及原文快照；当前账号报告与未同步本机文字分开说明。反馈获取失败显示未读取成功，不当作空列表；反馈没有公共本机缓存，登录过期时无法离线读取。展开原文与网络回调均检查当前身份和会话归属，读取不触发原报告缓存、保存或完成操作。

## 验收要求

自动回归覆盖教师本人、同校其他教师、同校管理员、他校用户和学生本人/其他学生权限；报告版本恰好更新、相同操作重试、编号复用不同正文、教师换号后的迟到结果、身份异常、空白或超长反馈、已完成会话及不允许重做任务。SQLite和pg-mem适配器已验证旧库新增表保留数据；真实PostgreSQL MVCC、并发与迁移仍须用真实服务验收。

实际前端API模块与隔离SQLite HTTP已完成“保存一版报告 → 教师反馈 → 学生读取原版关联 → 学生自行保存新版 → 教师重新读取新版并再次反馈”，重启后原反馈快照仍保留。组件回调另有自动测试；浏览器连接通道仍不可用，完整真实页面操作尚未验收，不能把接口通过等同于教师课堂试用完成。
