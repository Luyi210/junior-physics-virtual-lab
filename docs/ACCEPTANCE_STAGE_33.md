- 每次提问深拷贝实验上下文，回复附提问时的参数、物理时刻、自动/手动记录数量及RC开关历史。参数、时刻或记录发生变化时明确标注，保留历史回复。例如100 g条件下发出的弹簧问题，即使收到回复时已调到200 g，也显示它依据的100 g条件。
- 浏览器没有`crypto.randomUUID`时使用`getRandomValues`生成会话编号。安全随机源均不可用时仍可打开助手并获得本地引导，明确提示未发送联网请求。身份变化、取消和失败降级的隔离行为保留。
- 双缝λ=700 nm、d=0.1 mm、L=3 m时，±20 mm屏内只有中央亮纹。读尺及默认“先做哪一步”入口先说明限制，提示固定波长、一次只缩短屏距或增大缝间距；能读尺但没有记录时给出A/B定位及间隔计数步骤。旧记录仍按原参数分析，支持“上次测量的波长是多少”等问法，不用当前屏幕否定历史读数。
- 首页“平抛运动怎么探究”“怎样控制变量”及记录追问提供具体方案，不再反复返回同一选实验提示，不假称已收到实验数据。
- 本地引导随服务端重算结果进入AI参考资料，并明确操作限制、当前条件与历史记录边界。本轮只测试合成供应商响应和本地降级，未调用真实付费AI。

## 物理模型与显示

| 问题与复现 | 修正 |
| --- | --- |
| 薄透镜f=15、u=30.5时，性质写“等大”而结论写“缩小”；焦点附近有限像被宽容差当成无穷远 | 统一焦点/2f的数值相等边界；读数容差不再改变物理分类 |
| 摩擦实验玻璃板10 N记录1.50 N起动阈值后换毛巾，仍比较旧阈值，出现负的“比起动阈值低” | 材料或压力改变时清除当前旧阈值，保留已保存的完整匀速测量记录 |
| 曲面镜二维镜顶与射线折点错位，焦点预设的反射方向由任意屏幕端点决定；二维/三维各用不同几何 | 两种视图共用球面、法线反射、物体/焦点/像点坐标。代表光线按实际球面法线反射，像位置和性质仍用近轴公式，明确球差与近似；视野外像不强行挪回 |
| 气体p–V的1e−5至1e−4 m³范围被强制扩展至约0.001 m³，曲线被挤压；小数坐标和初始RC刻度可能倒退为0 | 横轴使用真实非恒定范围，仅恒定数据补跨度；按刻度间隔选择数字精度 |
| 折射实验n₁=n₂时，二维/三维仍画反射光 | 同折射率普通非磁性介质不画反射线，保留透射；不同折射率及全反射原逻辑保留 |

球面镜近轴公式及适用范围参考[OpenStax 球面镜](https://openstax.org/books/university-physics-volume-3/pages/2-2-spherical-mirrors)。同折射率普通非磁性介质的无反射边界参考[UT Austin 电磁学讲义](https://farside.ph.utexas.edu/teaching/em/lectures/node104.html)。本轮没有增加完整Fresnel强度或偏振模型。
