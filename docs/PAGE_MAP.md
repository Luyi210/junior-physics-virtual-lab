# 页面入口与层级

当前 V2 采用“一个总入口、两个正式端口”的结构。

```text
平台总入口  /
├─ 学生探索空间  /student
│  ├─ 学生身份登录与个人实验航行台（班级任务、当前会话、证据与档案；也可选择游客自由探索）
│  ├─ 光现象专题  /student/explore/light
│  │  ├─ 基础光现象：三棱镜色散、小孔成像、光的反射、光的折射
│  │  ├─ 自然与生活应用：三原色、日月食、平面镜、凹面镜和凸面镜
│  │  ├─ 透镜与视觉：放大镜、光具座、照相机、眼睛、视力矫正、组合透镜
│  │  └─ 凸透镜精密实验工作台  /lab/lens（学生端光学高级工具）
│  ├─ 声音实验场  /student/explore/sound
│  │  └─ 产生与传播、声音三要素、噪声控制、超声与次声
│  ├─ 力学工坊  /student/explore/mechanics
│  │  └─ 运动速度、摩擦力、杠杆、压强、浮力与浮沉
│  ├─ 电学连接室  /student/explore/circuit
│  │  └─ 串并联、欧姆定律、电功率、电流磁效应
│  ├─ 热学观察站  /student/explore/thermal
│  │  └─ 温度测量、沸腾、熔化与凝固、蒸发
│  └─ 物质测量室  /student/explore/measurement
│     └─ 天平测量、质量与体积、固体密度、液体密度
└─ 教师端  /teacher
   ├─ 教学总览      /teacher
   ├─ 账号与成员    /teacher/accounts
   ├─ 班级管理      /teacher/classes
   ├─ 实验备课      /teacher/lessons
   ├─ 课堂控制台    /teacher/live
   └─ 学情报告      /teacher/reports
```

## 两个正式端口的区别

- 学生探索空间：进入时可使用真实学生账号登录，也可选择游客自由探索。登录学生会看到个人实验航行台，集中呈现所属班级、下一项任务、进行中会话、任务证据统计与历史实验档案；任务启动后创建后台实验会话，并把关键操作和观察同步为自己的学习轨迹。每个非光学领域均包含“课本总览、动态实验、实验说明、生活应用”四层结构。
- 学生首页：六个物理领域均提供独立动态预览；开放问题区由本地物理知识图谱驱动，覆盖 36 个实验节点、概念、器材、生活现象、观察证据与实验关联。自定义提问会返回匹配路径、可信度、相邻实验和继续追问，不调用 LLM。
- 声音实验场：采用专属声学信号观测界面，包含玻璃罩传声、棉线电话、可保存基准时间波形的声音三要素、三环节噪声控制和超声去程/回程测距；玻璃罩要求固定接收距离并形成至少 40% 空气量差异的强对照，粒子只在平衡位置附近往复振动，疏密相位向前传播，并提供可暂停、可点选粒子、自动标注疏密部、位移—时间曲线同步、双时刻空间快照与传播方向判断；棉线电话要求依次记录松线、绷紧和捏住棉线三种状态，用振动链路的恢复与中断证明固体能够传声且传播需要连续介质；三要素实验明确示波器横轴为时间、显示 T=1/f，并要求分别完成频率—音调、振幅—响度和波形—音色三项单变量证据；噪声要求三个环节分别测试，测距要求三个时间点支持比例关系，判定结果同步进入 Harness 和学生实验证据。
- 非光学实验循环：力学、热学、电学和测量实验均先要求学生形成预测或准备装置，再进行有效条件判断和数据记录。速度要求固定路程改变高度；摩擦包含静摩擦随拉力变化、突破最大静摩擦、回调到滑动匀速，以及压力/粗糙程度双因素证据；压强要求压力/面积双因素证据；浮力要求正式示数锁存、碰底支持力误差演练和同一物体更换液体；杠杆除多组力矩比稳定外，还要求固定力与悬点距离，对照90°和30°斜拉，测量支点到力的作用线的垂直距离。温度计包含量程、位置、稳定、平视规范和俯仰视差演练；沸腾要求单条曲线的升温段和跨越至少10秒的平台证据，并固定水量与火力对照不同气压下的沸点；冰熔化要求升温段和0℃平台；蒸发要求温度、面积、风速三项单变量称量证据。托盘天平要求两次独立归零调平和重复称量，砝码必须先拿镊子再取放，并提示由大到小的规范顺序；固体密度把气泡附着、未完全浸没做成真实装置状态并锁存规范V₂；液体密度包含空杯/总质量差量法、转移残留误差、视差误差与不同体积复测；质量—体积关系要求每个描点经历清零、制样、初测、取下、再清零、独立复称，以平均质量描点，还要求制造并恢复一次不写入正式数据的零点偏移异常，且不同材料始终保存在独立数据集中。串并联要求串联/并联双拓扑证据、断路诊断以及9V受保护短路演练后的断电—拆线—复位恢复，欧姆定律要求大量程试触后换小量程正式读数，并完成 I-U 正比和 I-R 反比双任务；电功率要求电压—功率与时间—电能双证据，以及7.5V过压锁定—恢复安全电压诊断；电磁铁除匝数、电流、铁芯三因素和温升保护外，还要求在同一配置下正反接电源，用小磁针证明磁极互换而磁性强弱不变。21 个非光学节点现已全部采用独立实验台和预测—证据闭环。
- 光学动态教程：色散提供三项定值操作验证；直线传播、反射、折射、色光混合、天体现象、平面镜、曲面镜、不可见光及六个透镜模块均提供专属分镜、页面聚光、男声朗读、真实操作事件检测、预测互动和教程完成页。
- 全局物理视觉层：主界面、学生端、教师端和实验页共享情境仪表系统；系统根据当前领域与实验自动显示对应公式、测量刻度、动态光路/波形/电荷/受力/热粒子或测量图形，移动端自动简化。
- 全站引导分为三层：页面首次引导用于解释页面结构，任务提示条用于显示真实课例要求，光光动态教程用于等待并指导具体实验操作；三者不再混用。
- 教师端：面向课程组织、课堂演示和学习过程观察。进入时进行真实教师身份认证；账号与成员页管理学生身份，班级页读取真实班级与成员，实验备课页使用真实课例库并把任务发布给指定班级。教学总览的学生、班级和任务指标来自后台；实时课堂与报告页面仍保留本地演示工作区作为离线降级。
- 凸透镜精密实验工作台不再作为独立端口，它属于学生端光学探究中的高级实验工具。
