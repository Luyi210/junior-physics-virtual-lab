# 第十五阶段：课堂报告缓存隔离与副本保护

日期：2026-11-11（Asia/Shanghai）。状态：完整质量门禁、15组隔离 HTTP 联调和5项只读预览检查通过；真实浏览器与真实 PostgreSQL 验证仍未进行。

本阶段处理第十四阶段留下的课堂报告缓存边界：旧缓存仅含学生和会话 ID，无法区分后台及学校；旧异步响应和跨标签草稿也需要明确保留规则。本轮采用固定学生通道的 v3 缓存，提供旧数据及异常副本的只读出口、未落盘正文保护和明确恢复，并在完成实验前核对跨页草稿。保留既有四段报告、后台接口及高中读数显式选择流程，没有自动迁移旧数据或新增数据库迁移。

## 身份和缓存

- `studentRecordScope` 只读取学生通道的登录元数据，不跟随高中原始档案选择器的教师、游客选项，也不使用教师令牌。报告、任务中心与初中自动同步共用此边界；高中原始档案本身仍保留独立的归属选择。
- 身份键包含 API 命名空间、学校 ID、学生 ID。报告在其下区分会话及标签页；活动会话和事件队列使用对应的 v3 身份键。
- 每次页面生命周期使用新的随机草稿编号，不复用可能被复制标签页继承的 `sessionStorage` 编号。同一页面内路由切换仍使用同一仓库；刷新或新开页面后的编号不同。刷新前已写入本机的草稿保留为其他页面副本，需要完整预览并明确恢复，不自动接管或删除原稿。
- 令牌续期保持同一缓存键，但增加身份修订，使旧回调失效。切换学生、学校、后台、退出及到期后，操作与请求回包重新检查捕获的身份。旧保存回包不能清除原待同步草稿，也不拿新身份接着处理旧请求。
- 本机解析令牌 payload 只选择缓存与界面状态，不验证服务端签名、不替代鉴权。真实账号、学校、会话与权限仍由 API 校验。
- 原学生令牌到期后，本机缓存和副本面板只读，可以显式查看及备份；不会自动 GET、编辑、同步、开始或完成课堂任务。退出、无效身份、演示模式不会读取学生课堂缓存。
- 旧 v2 报告、全局活动会话和全局事件队列原位保留。正常 v3 流程不读取、认领或迁移它们；只有下述旧报告面板可在明确操作后查看限定范围的旧报告数据。

## 只读副本出口

“升级前的本机副本”只在点击后扫描当前学生 ID、当前会话的精确 v2 键，按原标签页分别呈现。旧键没有后台命名空间，即使学生 ID 相同、payload 内有学校字段，也只标为来源未验证，不能当作属于当前后台的账号记录。

查看与 JSON 备份保留原键、原始 payload、读取时间及边界说明。全部旧标签页草稿均保留，包括孤立草稿、空值和损坏内容；身份字段与键不符时不渲染为正常正文，仍可显式备份原文。扫描或内容读取失败保留错误及部分读取标记，无法读到的字节不伪装成已备份。导出没有长度截断，也不上传、合并、删除或补写。

“其他页面草稿与异常副本”从当前 v3 身份与会话读取其他标签页草稿；正常本页草稿留在编辑器，不重复放入列表。本页损坏草稿和损坏或身份不匹配的账号缓存提供原文备份。正常账号缓存不会作为异常副本重复导出。页面处于读取错误状态时，这两个副本入口仍独立保留。

面板挂载不扫描正文。旧查看、下载回调在身份修订、学生、学校、后台、路由变化或卸载后失效。下载动作在创建 URL 前后检查权限；准备期间身份失效时不点击链接，并释放 URL。此处描述的是代码与测试覆盖，不代表实际浏览器下载已验收。

## 未落盘正文与恢复协议

编辑器在尝试写入本机前保留完整四段正文及原账号版本。写入失败的副本保存在当前页面的模块内存中，按稳定身份键与会话隔离，不跟随续期修订号清除。路由离开、组件重挂、到期及同身份重新登录后仍可明确查看；其他账号不可见。副本不会自动加入新挂载的编辑器或上传，也不会因 GET 或保存回包而清空。刷新或关闭页面可能丢失；离开提醒只是补充，不能替代及时导出。

“未落盘正文”和有效的“其他页面草稿”分别提供明确恢复按钮。两者都先提供完整正文预览，说明将替换当前待同步稿的四个字段；旧 v2 和异常原文不具有自动恢复入口。恢复确认绑定身份修订、会话、来源内容和目标编辑器/缓存快照，来源或目标变化后必须重新预览。

仓库以来源原版本号建立新操作，不擅自改用最新账号版本；一次本机写入成功才替换本页草稿，写入失败不先清空旧稿。原版本与已知账号版本不同会进入冲突核对，不自动上传覆盖；版本相同进入正常待同步流程，后台继续进行版本校验。过期只读身份、已完成会话或当前报告不可读时不允许恢复为可上传草稿。

其他页面来源始终保留，可继续导出；相同四段文字成功写入本机后，才移除对应未落盘内存副本。读取、下载或仅收到远端响应不会完成这一步。已落盘不等于已保存到账号，后续冲突或网络失败仍需处理。

## 完成会话前的处理

1. 只针对当前学生、学校和云端返回的活动会话操作，不继承另一个身份的本机活动指针。
2. 检查当前页面中该身份、会话的未落盘正文；存在时必须先核对并成功写入同份文字，不能只导出后跳过。随后列出当前会话全部 v3 页面草稿；读取异常、损坏内容或扫描清单变化会阻止完成。本页草稿存在但账号缓存缺失时，也不能按“没有待同步内容”继续。
3. 同步本页草稿，补传该会话的初中事件队列，再检查是否出现新编辑。队列损坏、写入失败或身份变化不作为成功补传。
4. 其他标签页仍有有效待同步草稿时，第一次点击显示确认区。学生可先回原标签页保存或显式备份；也可选择“我理解并完成已保存版本”。该选择不会上传、合并或删除其他草稿。
5. 确认绑定当前会话和全部草稿的完整原始内容。第二次点击前及同步后复核，发生变化需要重新确认；本页新增草稿仍必须先保存。完成 POST 前再次检查未落盘正文，防止等待期间新增内存副本；“完成已保存版本”不能绕过这项检查。
6. 完成后只读的是后台已保存报告。留在本机的其他草稿不能再写入这次会话，仍可查看及备份。完成不是教师评价，也不保证报告非空或所有页面内容已上传。

初中自动事件仍要求明确匹配课堂 URL 的任务、会话及 module/mode。队列按身份分隔，每批最多500条；旧身份回包不删除队列，确认移除依据完整发送内容，不只比较事件 ID。同编号不同内容的队列会阻止补传并保留原文。每轮只补传开始时的集合；结束时若本次会话还有新增或变化后保留的事件，抛出待重试提示并阻止完成，不无限补传。高中及未知实验不会借用初中队列作为课堂证据。

## 保留的限制

`localStorage` 没有跨标签页原子事务。逐次身份核对、键清单复核和完成前二次确认不能锁住其他页面，也不能排除另一个页面在最后检查后继续写入。同步采用服务端版本与操作编号校验；本机异常或未同步副本优先保留，不宣称所有并发写入都可自动合并。

当前页面只能知道自己内存中的未落盘文字，无法检查另一个页面尚未写入存储的内存副本。内存保护也不能跨刷新或关闭持续保存。离开提醒和完成前检查均不应表述为数据绝不丢失。

本轮仍是四段可编辑文字报告，没有新增类型化读数云附件、完整修改历史、教师批注/评分、正式审核状态或旧记录自动迁移。副本导出只保存已读到的内容，不能修复存储不可读的问题，也不等同于云端备份。商业部署、教师审阅和真实课堂反馈仍需独立验收。
